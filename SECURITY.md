# Security policy

## Reporting a vulnerability

Please do not file public issues for exploitable vulnerabilities. Use GitHub's
private vulnerability reporting for this repository, or contact the
maintainers through the organization profile if private reporting is
unavailable. Include affected versions, impact, and a minimal reproduction;
redact credentials and user data.

The maintainers will acknowledge reports and coordinate a fix and disclosure.
No response-time guarantee is currently offered.

## Scope

Reports involving provider credentials, workspace file access, command
execution, plugin/MCP configuration, the local HTTP listener, session data,
and release artifacts are in scope. The project is early-stage; review
`docs/security/threat-model.md` for known boundaries and limitations.
